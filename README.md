# CONFIGURACIÓN DE ARMBIAN EN LA ORANGE PI ZERO 2W PARA PRIMEROS USOS
## Descripción

Este repositorio describe la instalación y configuración necesaria del Sistema Operativo (SO) Armbian, basado en Debian 12 (Bookworm) para los primeros usos y el correcto funcionamiento de los servicios que se desee instalar y/o ejecutar.

El repositorio está organizado en carpetas que contiene scripts y configuración correspondiente. Cada una de ellas contiene la documentación técnica necesaria para el correcto funcionamiento del SO. Algunos pasos se pueden omitir siempre y cuando no formen parte de los requisitos previos de algún servicio del sistema que se desee implementar.

Tener en cuenta que gran parte de la configuracion y pasos de instalación son altamente compatibles con otras placas de la familia de ORANGE PI e incluso con Raspberry Pi. Sin embargo configuraciones específicas de hardware (como asignación de GPIOS, módulos de Kernel) pueden variar según el modelo de SoC utilizado. Pero ese tipo de configuración no se ve en este repositorio.

En este repositorio se documentan algunos servicios específicos. El sistema operativo queda preparado para incorporar otros servicios.
